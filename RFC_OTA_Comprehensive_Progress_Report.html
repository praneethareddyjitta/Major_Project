4. Complete Circuit Design Documentation

Architecture Description

The operational transconductance amplifier utilizes a single-stage Recycling Folded-Cascode (RFC) architecture with complementary subthreshold input transistors and cross-coupled local positive feedback:

Figure 1: Complete circuit schematic of the proposed Recycling Folded-Cascode OTA (MDPI Electronics 2025, 14, 1543).
  1. Complementary Subthreshold Input Stage: Comprises NMOS pair M1a, M2a (15/0.5) and PMOS pair M1b, M2b (30/0.5). Both pairs operate in weak inversion (Vov < 0), where gm/Id approaches 25–28 S/A. Oversized gate areas suppress 1/f flicker noise. The complementary NMOS+PMOS structure extends the input common-mode range from 0.8 V to 1.7 V.
  2. Two-Path Recycling Folded-Cascode: Input current is split into Path 1 (M1a, M2a) and Path 2 (M1b, M2b). Cascode transistors M3a, M4a steer Path 1 current directly to the output, while M3b, M4b steer Path 2 current into the recycling mirrors at node X.
  3. Recycling Mirrors with Cross-Coupled Positive Local Feedback: The active load is split into three branches with aspect ratios defined by k = m + 1 (m = 1/3, k = 4/3):
    • Diode-connected unit branch (Ratio 1): M5c, M6c (15/2) and M7c, M8c (45/10).
    • Cross-coupled positive feedback branch (Ratio m = 1/3): M5b, M6b (5/2) and M7b, M8b (15/10). Generates negative conductance that boosts impedance at node X.
    • Output branch (Ratio k = 4/3): M5a, M6a (20/2) and M7a, M8a (60/10). Delivers amplified currents to outputs.
    Overall effective transconductance: Gm = gm1a + [k / (1 + m)] gm1b = gm1a + gm1b.
  4. Deep-Triode Common-Mode Feedback (CMFB) Circuit: Tail current sink M11 (2/0.5) is degenerated by parallel deep-triode NMOS transistors M13 and M14 (2.5/2), directly driven by the differential outputs.
Figure 2: Wide-swing cascode constant-current biasing circuit (MDPI Electronics 2025, 14, 1543).

5. Simulation Verification and Waveform Results

A. DC Operating Point Analysis (Status: SIMULATED SUCCESSFULLY ✅)

Spectre DC simulation outputs (spectre.dc and results/curr_raw/op.dc) demonstrate complete convergence of the baseline operating point:

  • Supply Voltage: Vdd = 1.80 V, Vgnd = 0 V.
  • Total Quiescent Current: Itot = 3.23 μA drawn from Vdd (paper reported 3.02 μA including 270 nA bias network).
  • Core Power Dissipation: Pcore = 1.8 V × 2.69 μA = 4.84 μW (paper reported 4.50 μW).
  • Current Partitioning:
    • Current in M9, M10 branches: 916 nA each.
    • Input pair currents: Id1a = Id2a = 458 nA, Id1b = Id2b = 458 nA.
    • Output branch current: Id7a = Id8a = 610 nA.
    • Diode-connected mirror branch: Id7c = Id8c = 343 nA.
    • Cross-coupled positive feedback branch: Id7b = Id8b = 115 nA.
    • Ratio check: 610 nA : 115 nA : 343 nA = 4/3 : 1/3 : 1 (Matches theory exactly!).
  • Weak Inversion Biasing: At Id = 458 nA, the NMOS input transistors exhibit Vgs = 0.416 V against Vth0 ≈ 0.46 V, yielding an overdrive Vov ≈ -44 mV. This confirms subthreshold operation with transconductance efficiency gm/Id = 23.4 S/A.

B. AC Analysis (Status: PARTIALLY SIMULATED / AUDITED BUG ⚠️)

An AC frequency sweep was executed using tb_ac_openloop.scs and recorded in results/ac_ol_raw/ac.ac. The simulated Bode response is plotted below:

Figure 4: Spectre AC Analysis: Differential Frequency Response from ac.ac (Gain = 40.35 dB, UGBW = 2.5 Hz due to DC common-mode pull-down).
Technical Audit Finding on AC Simulation:
The simulation produced a peak DC gain of 40.35 dB with a 0-dB crossover at 2.5 Hz, rather than the target 97.23 dB and 2.91 MHz reported in the paper. Investigation of tb_ac_openloop.scs reveals the root cause:
The testbench employed 1 GH inductors from outputs to inputs (Lfb1 (voutm inp) inductor l=1G) to establish DC closed-loop stabilization. However, because the open-loop DC output naturally settled at 0.372 V, the feedback loop dragged the input gate voltages down from the intended 0.900 V to 0.372 V. At 0.372 V, the NMOS input transistors were almost completely turned off, collapsing the stage transconductance Gm by orders of magnitude.
Remedy: The DC common-mode bias must be fixed at 0.900 V using balanced differential common-mode sources, or the CMFB loop must be tuned to stabilize the outputs at 0.900 V before running open-loop AC analysis.
